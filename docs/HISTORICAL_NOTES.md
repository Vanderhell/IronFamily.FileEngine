# Historical Notes

The repository still contains historical or compatibility-oriented code outside the active product scope.

## Not active supported engines

- `BJX`
- `ICF2`
- `ICFX`
- `ICXS`

These may remain in source form for compatibility work, vectors, or migration evidence, but they are not part of the active engine set described by the public documentation.

## Delta naming

`IRONDEL2` appears in code and vectors as an `IUPD` incremental algorithm identifier. It is not a fourth active top-level engine.
